# Security

This extension handles OAuth access, email delivery, prospect data, and optional
provider credentials. Treat those as sensitive even when they are stored only
in a local Chrome profile.

Report suspected vulnerabilities privately to the repository administrators
through an existing Vela company channel. Do not open a public issue and do not
include credentials, cookies, CSRF tokens, email content, customer data, or
exploit details in screenshots or chat.

If any credential may have been exposed, revoke or rotate it immediately.
Removing it from a file, browser setting, or current commit is not sufficient.

Security fixes use the normal pull-request and CI process. Emergency changes
require retrospective review, evidence, and a follow-up test.
